# MPC-RL Hierarchical Navigation for Differential Drive Robot
PhD Preliminary Results — ROS 2 Humble + Gazebo Classic

## Architecture
- High-Level: Reinforcement Learning (PPO via Stable-Baselines3)
- Low-Level: Model Predictive Control (CasADi)

## Simulation Environment
- ROS 2 Humble
- Gazebo Classic 11
- TurtleBot3 Burger

## World Configurations
- World B: U-Shaped Trap
- World A: Structured Corridor
- World C: Dynamic Obstacles
